# Issue tracker: GitHub

Project issues and specifications live in GitHub Issues for this repository. Use `gh issue` or the GitHub web interface to create, read, update, label, and close issues. Infer the repository from the Git remote once it is connected.

## Pull requests as a triage surface

PRs as a request surface: no. External pull requests are reviewed as code changes, not automatically treated as feature requests.

## When a skill says "publish to the issue tracker"

Create a GitHub issue in this repository.
